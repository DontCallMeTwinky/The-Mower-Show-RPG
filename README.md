# The-Mower-Show-RPG
an rpgmaker 2003 rpg based on the mower show

to play, extract one of the .7z files in this repository and run the "RPG_RT.exe" file inside it. 

yuoll need to install rpgmaker 2003 to play it, which is available to buy here: https://store.steampowered.com/app/362870/RPG_Maker_2003/

i havent tested this on another system so it mite have problems. another player has told me they had to open the game in the rpgmaker 2003 editor to get it to load the rtp files correctly, so i added another version of the game that should be compatible with more recent rpgmaker 2003 versions. if anything goes wrong for yuo, pls leave a comment or something at: deviantart.com/DontCallMeTwinky

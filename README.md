# The-Mower-Show-RPG
an rpgmaker 2003 rpg based on the mower show

to play, extract the .7z file in this repository and run the "RPG_RT.exe" file inside it. 

yuoll need to install rpgmaker2003 to play it, which is available to buy here: https://store.steampowered.com/app/362870/RPG_Maker_2003/

i havent tested this on another system so it mite have problems. another player has told me they had to open the game in the rpgmaker editor to get it to load the rtp files correctly. if anything goes wrong for yuo, pls leave a comment or something at: deviantart.com/DontCallMeTwinky
